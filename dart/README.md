# zepben_protobuf

Dart protocol buffer messages and gRPC clients for the Zepben Energy Workbench (EWB), generated from
[zepben/ewb-grpc](https://github.com/zepben/ewb-grpc).

```yaml
dependencies:
  zepben_protobuf: ^1.10.0
```

To build from source, see the [ewb-grpc README](https://github.com/zepben/ewb-grpc#dart).
